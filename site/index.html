LOCAL-FIRST · RUST 2024

把零散提示词，组织成图。

Promptr 用 Fragment 保存正文，用 Prompt 编排有序引用，再通过一门小型 DSL 查询、修改，并确定性地渲染为规范 XML。

THE MODEL

两种节点，一套明确语义

名字既是 DSL 符号，也是 XML 元素名。组合保持顺序和重复引用；提交后的图始终无环。

01

Fragment · 内容叶子

保存可复用的 XML 1.0 文本。正文不会悄悄变成 XML 结构。

02

Prompt · 有序组合

引用 Fragment 或其他 Prompt；共享子图和重复子项都被保留。

03

Catalog · 持久目录

SQLite 保存节点、描述与标签，并支持全局或可达子图内搜索。

OUTPUT CONTRACTS

人看得清，机器也读得稳

交互查看用 human，程序集成用版本化 JSON，只取 XML 时使用 raw。

  • 查询结果在事务内缓冲，提交成功后才发布
  • 确定性的规范 XML，保持组合顺序与重复引用
  • 配置、状态、备份、一致性检查与索引重建齐备
  • Linux、macOS 与 Windows 使用平台原生应用目录
